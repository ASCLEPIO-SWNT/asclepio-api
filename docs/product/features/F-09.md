# F-09 — Datos sintéticos y guion de demo

> `sdd: false`. Es una tarea de soporte y no una feature de usuario final.

**Objetivo:** tener un seed idempotente con datos sintéticos y un guion de demo de extremo a extremo reproducible.

**Usuarios:** el equipo de desarrollo y los evaluadores del curso.

## Criterios de aceptación globales
- **F-09.AC1** `prisma db seed` es idempotente: ejecutarlo dos veces no duplica datos.
- **F-09.AC2** Crea un tenant, una sede y un usuario por rol, todos sintéticos y con contraseñas solo de desarrollo documentadas.
- **F-09.AC3** Crea pacientes y atenciones sintéticas que cubren los niveles I–V, incluido el caso de ejemplo de las 7:42 p. m.
- **F-09.AC4** Todos los datos de desarrollo llevan el prefijo `DEV-<nombre>-` y nunca hay datos reales.
- **F-09.AC5** `docs/verification.md` contiene el guion de demo paso a paso (móvil → web → reportes).
